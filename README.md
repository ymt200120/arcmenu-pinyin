# ArcMenu Pinyin

ArcMenu Pinyin is a third-party GNOME Shell extension for grouping Chinese app names by pinyin in ArcMenu's **All Apps** view. It uses `#` and `A`–`Z` buckets with a fixed 27-key jump panel, works with the official ArcMenu extension at runtime, and does not modify ArcMenu's files.

中文文档：[README.zh-CN.md](README.zh-CN.md)

English documentation: [README.en.md](README.en.md)

The current release targets ArcMenu 70.x and declares support for GNOME Shell 45–49. ArcMenu 70.0 has been verified on GNOME Shell 46.0 (Ubuntu 24.04). Other combinations have not been verified; the extension may decline injection when ArcMenu's structure does not match.

The extension is independent of ArcMenu and is not affiliated with or endorsed by the ArcMenu project. The original Alphabet Jump List from this repository was upstreamed through [MR !284](https://gitlab.com/arcmenu/ArcMenu/-/merge_requests/284) and is now called Bucket Jump List upstream.

For installation, updates, troubleshooting, development commands, credits, and license details, see the language-specific README above.
